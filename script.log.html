Introdução à Lógica de Programação

O que é Lógica de Programação?

Quando você ouve falar sobre esse tema, o primeiro pensamento costuma ser: “Será que vou ter que aprender a pensar como um computador?”

No fundo, a lógica é exatamente isso: a arte de quebrar grandes problemas em etapas simples, claras e organizadas. É através desse método que o estudante estrutura seu pensamento para encarar e resolver os primeiros desafios práticos do curso.

Ex: faça um algoritmo que peça para o usuário digitar seu nome e sua idade. Como você resolveria isso? Antes de escrever qualquer código, vamos pensar no problema:

  1. Precisamos pedir o nome do usuário.
  2. Depois, precisamos pedir a idade.
  3. Por fim, precisamos exibir essas informações.

INÍCIO
Leia o nome do usuário.
Leia a idade do usuário.
Exiba o nome e a idade.
FIM

Caro estudante, agora você vai entender o que é uma variável, como atribuir um valor a ela e como organizar o pensamento para transformar esse algoritmo em código. Uma variável é um espaço na memória usado pelo programa para guardar uma informação que poderá ser utilizada posteriormente. No nosso problema, temos duas informações:

  • nome “Carlos”
  • idade 18

Por que precisamos de uma variável nesse problema? Porque o programa precisa guardar o nome e a idade que recebeu para poder utilizá-los depois.

let nome = "Carlos";
let idade = 18;

A primeira linha não lê o nome do usuário; ela atribui “Carlos” diretamente à variável nome. A segunda linha atribui o valor 18 diretamente à variável idade. Veja bem, existem maneiras de resolver esse problema. Esta é uma forma de iniciar, escolhida para que você compreenda como utilizar uma variável. Pense, existem diferentes maneiras de resolver esse problema. Esta é apenas uma forma de iniciar.

Agora, você está preparado para aprender uma nova maneira de pensar? O mais importante é você entender a diferença entre: Const, Let e var. Agora você está preparado para aprender um novo poder? Vamos nessa, vamos chegar ao tesouro!

O let é utilizado quando criamos uma variável cujo valor pode ser alterado durante a execução do programa. Para exemplificar, imagine a sua idade: você informa ao algoritmo quantos anos tem hoje, mas, um mês depois, você faz aniversário.

Nesse cenário, o valor da sua idade muda no decorrer do tempo — e é exatamente para guardar esse tipo de informação mutável que usamos o let. Enquanto o let aceita mudanças, o const (abreviação de constante) é usado para criar variáveis cujo valor nunca muda depois de ser definido pela primeira vez. Se você tentar alterar o valor de um const, o programa retornará um erro. Para contrastar com o exemplo da idade, podemos usar o ano de nascimento ou o CPF. Você faz aniversário e sua idade muda (let), mas o ano em que você nasceu permanece exatamente o mesmo para sempre (const). O var foi a forma original de declarar variáveis no JavaScript desde o surgimento da linguagem. No entanto, com a evolução da tecnologia, ele caiu em desuso por conta de comportamentos imprevisíveis que geravam muitos bugs no código. A principal diferença é que o var possui escopo abrangente (global ou de função) e permite que uma variável seja declarada novamente sem emitir alerta de erro, diferente do let e do const que respeitam o escopo de bloco (como o interior de uma estrutura if ou for).

Olhe o exemplo abaixo:

let nome = prompt("Digite seu nome");
let idade = prompt("Informe a sua idade");
console.log(`Seu nome é ${nome}, você tem ${idade} anos de idade`);
