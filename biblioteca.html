ARTIGO 01 / 08

Variáveis

Variáveis são espaços na memória usados para armazenar valores que podem mudar durante a execução do programa. Pense em uma variável como uma caixa identificada por uma etiqueta: a etiqueta é o nome e o conteúdo é o valor.

let nome = "Script.log";
let idade = 18;

console.log(nome);
console.log(idade);
Para lembrar
  • Declarar cria uma variável; atribuir define seu valor.
  • O sinal = representa atribuição.
  • Prefira nomes que revelem a finalidade da informação.
ARTIGO 02 / 08

Tipos de Dados

Strings representam textos, numbers representam números e booleans indicam verdadeiro ou falso. Embora o número 18 e o texto "18" pareçam iguais na tela, são tipos diferentes.

let nome = "Ana";       // string
let idade = 18;         // number
let estudando = true;   // boolean

console.log(typeof idade);
Para lembrar
  • Um número entre aspas é um texto.
  • Use valores lógicos para representar condições.
  • Escolha o tipo de acordo com a finalidade do dado.
ARTIGO 03 / 08

Operadores

Operadores aritméticos realizam contas. Operadores de comparação verificam relações entre valores, enquanto operadores lógicos permitem combinar condições.

let soma = 2 + 3;
let resto = 8 % 2;
let maiorDeIdade = 18 >= 18;

console.log(soma, resto, maiorDeIdade);
Para lembrar
  • = atribui; === compara em JavaScript.
  • % informa o resto de uma divisão.
  • Parênteses ajudam a organizar expressões.
ARTIGO 04 / 08

Condicionais

As estruturas if e else permitem que o programa escolha o que executar de acordo com uma condição. Apenas o caminho correspondente ao resultado será executado.

let idade = 18;

if (idade >= 18) {
  console.log("Maior de idade");
} else {
  console.log("Menor de idade");
}
Para lembrar
  • Uma condição precisa resultar em verdadeiro ou falso.
  • Apenas um caminho será executado.
  • Teste o limite e os valores próximos.
ARTIGO 05 / 08

Repetições

Laços repetem um bloco de instruções. No for, defina o início, a condição de parada e a atualização do contador.

for (let contador = 1; contador <= 5; contador++) {
  console.log(contador);
}
Para lembrar
  • Identifique início, condição e atualização.
  • Garanta que a repetição tenha uma forma de terminar.
  • Confira se o valor final deve ser incluído.
ARTIGO 06 / 08

Funções

Funções agrupam instruções reutilizáveis. Elas podem receber parâmetros e devolver um resultado com return.

function somar(a, b) {
  return a + b;
}

let resultado = somar(2, 3);
console.log(resultado);
Para lembrar
  • Parâmetros recebem os dados de entrada.
  • O retorno permite usar o resultado em outra expressão.
  • Prefira funções com uma responsabilidade clara.
ARTIGO 07 / 08

Arrays

Arrays guardam vários valores em uma lista. O primeiro item está no índice 0; length informa a quantidade de itens.

let notas = [7, 8, 9];

console.log(notas[0]);
notas.push(10);
console.log(notas.length);
Para lembrar
  • O primeiro índice é 0.
  • Quantidade de itens e último índice são diferentes.
  • Uma repetição permite percorrer os itens.
ARTIGO 08 / 08

Objetos

Objetos reúnem informações relacionadas em pares de chave e valor. Use a notação de ponto para acessar uma propriedade.

let aluno = {
  nome: "Ana",
  idade: 18
};

console.log(aluno.nome);
Para lembrar
  • Objetos JavaScript agrupam pares de chave e valor.
  • A notação de ponto consulta uma propriedade.
  • Portugol Studio não oferece objetos nativos.
