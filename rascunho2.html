Condicionais if/else

Vamos Estudar If/Else

O que são Tomadas de Decisão?

Na vida real, tomamos decisões o tempo todo baseadas em condições. Por exemplo: “Se estiver chovendo, levo um guarda-chuva; senão, vou de boné”. Na programação, a lógica é exatamente a mesma!

Para isso, utilizamos o if (se) e o else (senão). Eles permitem que o computador execute caminhos diferentes no código dependendo do resultado de uma condição.

Como funciona na prática?

Imagine que queremos verificar se um usuário é maior de idade para entrar em um evento:

let idade = prompt("Qual é a sua idade?");

if (idade >= 18) {
  console.log("Acesso permitido! Você é maior de idade.");
} else {
  console.log("Acesso negado! Você é menor de idade.");
}

Entendendo o Código:

  • if (idade >= 18): O programa testa se a idade digitada é maior ou igual a 18.
  • Bloco do if: Se a condição for verdadeira (true), o código entre as chaves `{}` do `if` será executado.
  • else: Se a condição for falsa (false), o programa pula o `if` e executa o código que está dentro do `else`.

Com essa estrutura, seu programa deixa de ser uma sequência engessada de passos e passa a reagir às informações que recebe!
