Laços de Repetição (Loops)

O que é um Loop? (Uma Analogia Simples)

Pense num treino de futebol ou numa aula de educação física: quando o professor diz "Dê 5 voltas no campo!", você não precisa de perguntar 5 vezes o que fazer. Você simplesmente corre uma volta, conta na sua cabeça, e repete a ação até completar as 5 voltas.

Na programação, um Loop (ou Laço de Repetição) serve exatamente para isso: diz ao computador para repetir um bloco de código várias vezes sem que precise de o escrever repetidamente.

1. O Laço while (Enquanto)

O while funciona como uma instrução de rotina: enquanto uma condição for verdadeira, o computador continua a fazer a tarefa.

Exemplo da vida real: Enquanto houver loiça na pia, continue a lavar.

let voltas = 1;

// Enquanto as voltas forem menores ou iguais a 3, continue a correr!
while (voltas <= 3) {
  console.log(`Você completou a volta ${voltas}!`);
  voltas++; // Soma +1 ao número de voltas
}

console.log("Fim do treino!");

O que acontece passo a passo?

  1. Começamos com voltas = 1.
  2. O programa testa: 1 é menor ou igual a 3? Sim! Escreve no ecrã e soma +1.
  3. Agora voltas = 2. Testa novamente: 2 é menor ou igual a 3? Sim! Escreve e soma +1.
  4. Agora voltas = 3. 3 é menor ou igual a 3? Sim! Escreve e soma +1.
  5. Agora voltas = 4. 4 é menor ou igual a 3? Não! O loop para e o programa segue em frente.
⚠️ Cuidado com o Loop Infinito!
Se esquecer da linha voltas++, o número de voltas nunca vai aumentar. O programa ficará preso a correr para sempre!

2. O Laço for (Para)

O for é uma forma mais organizada e compacta de escrever um loop quando já sabe **exatamente quantas vezes** quer repetir a ação.

//  (Início ;  Condição ; Incremento)
for (let i = 1; i <= 3; i++) {
  console.log(`Contando o número: ${i}`);
}

Desmontando as 3 partes do for:

  • let i = 1 (Início): Cria a variável contadora com o valor inicial.
  • i <= 3 (Condição): A regra que autoriza o loop a continuar rodando.
  • i++ (Passo): O que acontece ao final de cada volta (soma 1 na variável i).
